# Australian Cleaning Rags: Homepage

Static HTML homepage (desktop layout) exported from the Design canvas.

## Files

- `index.html`: the homepage (HTML, CSS and JavaScript in one file)
- `assets/`: 34 images and one video (`how-its-made.mp4`) used by the page

## Deploy on Vercel

1. Push this repository to GitHub.
2. In Vercel, choose **Add New > Project** and import the repository.
3. Framework preset: **Other**. Leave the build command and install command empty. Output directory: `.` (the root).
4. Deploy. Vercel serves `index.html` at the root URL.

## Open items before launch

- The Enquire Now popup is a placeholder. Paste the GoHighLevel form embed code into the `enquiry-modal` block in `index.html`.
- The hero and wholesale quote forms are not connected yet. Enquiry routing is still to be confirmed.
